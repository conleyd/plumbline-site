Integrations and data use

What Plumbline reads from each source

Every connector is read-only by default and requests the narrowest read permission the vendor offers. This page lists, for each source, what Plumbline reads, what it never reads, and the exact permissions it requests.

Rules that apply to every source

  • Read-only. A test in the codebase fails if any connector calls an HTTP method other than GET or HEAD, or a read-only query, unless that connector declares an allowed write. The few allowed writes are listed on the Security page; none of them touches data in the sources on this page.
  • Credentials. Tokens and keys are encrypted with AES-256-GCM under the company's own data key and decrypted only inside the task that calls the vendor. No person, including Plumbline staff, can view them; admin screens show only the scopes granted and the dates.
  • Revoke at any time. Revoking deletes the stored credential and stops queued work. It also calls the vendor's token revocation where the vendor offers it.
  • Upload instead. Each source has a file-upload alternative for companies that prefer not to connect it.
  • Rate limits. Each connector stays under the vendor's published limit, leaving headroom for the company's own tools.

Salesforce CRM

Used to measure AI revenue share, AI attach rate, revenue per sales rep, AI features live and priced, and AI ticket resolution from Service Cloud cases.

What we read

  • Products and price books (Product2, Pricebook2, PricebookEntry)
  • Opportunities and their line items (Opportunity, OpportunityLineItem)
  • Users and roles (User, UserRole)
  • Cases (Case)
  • Task and Event metadata only: type, created by, owner and dates
  • Product descriptions, held in memory to classify AI products and stored only as a SHA-256 hash

What we never read

  • Account contact details
  • Notes
  • Email bodies
  • Task and Event subjects, descriptions or bodies
  • Any object not listed on the left

Read-only

Access to Salesforce records is read-only. Large initial reads use Bulk API 2.0 query jobs; creating or cancelling a query job writes no record data. Plumbline caps its own use at 5% of the org's daily API request allocation.

Salesforce data is processed in Plumbline's cloud, not in the customer's org. Companies that install the optional Plumbline managed package store only connector configuration, license state and OAuth linkage in the package's own objects in their org. The package declares no write permission on standard objects. Its change-event triggers send only record IDs, changed field names and timestamps, and Plumbline then re-reads the records through the read-only API.

Without connecting: upload a CSV export of an opportunities report with product lines.

Microsoft Entra ID Identity

Used for single sign-on to Plumbline and, when the company enables it, to find which AI tools people sign in to, which AI apps have been granted access, and whether single sign-on is enforced on AI tools.

What we read

  • Users and groups
  • Sign-ins to applications
  • OAuth permission grants to third-party applications, and service principals

What we never read

  • Passwords
  • Mail
  • Calendar
  • Files

Permissions requested

Not requested: any mail, calendar or file scope, and any scope that writes to the directory. Reading sign-in logs requires an Entra ID P1 or P2 licence; the connect panel warns when a 90-day history is not available.

Read-only

Plumbline writes nothing to the directory. If the company sets up SCIM provisioning, the company's identity provider pushes users to Plumbline; Plumbline does not write back.

Without connecting: upload a CSV of users and app assignments, or a sign-in report export.

Ramp Spend

Used to measure AI spend per employee and to find AI tools that are expensed twice or bought outside approved channels.

What we read

  • Card transactions: merchant, amount, date, cardholder and the last four digits of the card
  • Users, to match cardholders to people

What we never read

  • Transaction memos
  • Full card numbers, which are not requested
  • Receipts, which are not downloaded

Permissions requested

Ramp permissions
RequestedWhy
transactions:readRead card transactions to find AI tools and their cost
users:readMatch each cardholder to a person

Not requested: card management and payments. Access is granted through OAuth 2.0 by a Ramp user with Developer API permission.

Read-only

Plumbline only reads from Ramp, once a day. It cannot issue, change or freeze cards, or move money.

Without connecting: upload a statement as CSV (date, merchant, amount, currency, cardholder email) or PDF. A memo column, if present, is dropped without being read.
